# Pasha Barbershop

Marketing demo site for **Pasha Barbershop** (صالون باشا / Paşa) — Plano, TX.

- Address: 6921 Independence Pkwy #180, Plano, TX 75023
- Phone: (214) 501-3715
- Booking: [Booksy](https://booksy.com/en-us/1061273_pasha-barbershop_barber-shop_36433_plano)

Built as a static Vite site for Railway. Content is synthesized from public Google/Booksy reviews and listings — **not affiliated** until the shop adopts it.

```bash
npm install
npm run build
npm start
```
